# Personal Portfolio

A responsive personal portfolio website built with HTML and CSS, created as **Level 1 - Task 1** of the Web Development Internship at **SARV Infotech Private Limited**.

## 👤 About

This portfolio introduces me, Archana Kumari, and showcases my skills, projects, and contact details in a clean, single-page layout.

## ✨ Features

- **Header section** with name and navigation menu
- **About section** with a short bio
- **Skills section** listing key technical skills
- **Projects section** showcasing sample project cards
- **Resume section** with a downloadable PDF resume
- **Contact section** with email, phone, and LinkedIn
- **Footer** with copyright notice
- Fully responsive layout that adapts to mobile and desktop screens

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox & Grid)
- Google Fonts (Poppins)

## 📂 Project Structure

```
task1-portfolio/
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open `index.html` directly in any web browser, **or**
3. In VS Code, right-click `index.html` and select **"Open with Live Server"**.
